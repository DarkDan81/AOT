# Лабораторная 5 — Мини-RAG с доказательствами

Авторы: Дущенко Даниил Александрович и Коваленко Евгений Юрьевич, группа К3341.

30 вымышленных документов по 24 абзаца, 100 уникальных вопросов, 30 без ответа. Train=60 и test=40; документы частей не пересекаются. Модель mistralai/ministral-3-14b-reasoning доступна в LM Studio на localhost:1234. Зависимости: rank-bm25, razdel, pydantic>=2, pandas, requests, pytest.

Из корня репозитория с активированной общей виртуальной средой:

```powershell
python -m lab05_mini_rag.build_data
python -m lab05_mini_rag.retrieve
python -m lab05_mini_rag.generate
python -m lab05_mini_rag.evaluate
python -m lab05_mini_rag.evaluate_challenge
python -m pytest lab05_mini_rag/test_contract.py -q
```

В случае проблем Windows с исходной рабочей папкой используйте из текущего корня: `.\.venv\Scripts\python.exe -I -c "import sys,runpy;sys.path.insert(0,'.');runpy.run_module('lab05_mini_rag.evaluate',run_name='__main__')"` (замените модуль для других команд).

Генератор продолжает журнал, пропуская сохранённые запросы. Для повторного независимого прогона перенесите старый results/predictions.jsonl. Не пересоздавайте данные во время эксперимента. Оба режима используют один prompt.txt и JSON Schema, одинаковые параметры. Повторных запросов и автоматического исправления JSON нет.

data/train.jsonl содержит эталоны; data/test.jsonl — только вопросы. evaluation_private/test_gold.jsonl читает оценщик, генератор его не открывает. Это процедурная изоляция в учебном репозитории, не защита от автора. SHA-256 фиксируются до LLM; retrieval_before_llm.json создан до первого запроса. Идентификаторы абзацев локальны документу. BM25 использует razdel, нижний регистр и исходный порядок при равных оценках.

Основные результаты: results/metrics.csv, scores.csv, answerable_confusion.csv, predictions.jsonl, error_analysis.md. Answer accuracy проверяет все эталонные значения с границами токенов; exact match публикуется отдельно. Пустые пары evidence имеют F1=1. Метрики answerable относительно полного документа и полноты реально переданного контекста разделены.

Дополнительная исследовательская проверка: `python -m lab05_mini_rag.challenge freeze`, затем `python -m lab05_mini_rag.challenge run`. 15 случаев и 30 ответов хранятся в challenge/. После наблюдаемого сбоя цитаты отдельно заморожены четыре варианта в challenge_replication/: команды `python -m lab05_mini_rag.replicate_quote freeze` и `python -m lab05_mini_rag.replicate_quote run`. Дополнения не входят в основные метрики и не являются независимым подтверждающим тестом; это целенаправленная диагностика.

Мы организовали работу по направлениям: документы и BM25; промпт и валидатор; метрики и анализ ошибок. Синтетические шаблоны и специально трудные составные вопросы ограничивают обобщение результатов.

Восемь запросов challenge_replication частично совпали с нагрузкой другой лабораторной на GPU. Дополнительные времена не используются для сравнения скорости; соответствующие флаги сохранены в CSV. Основные 200 запросов выполнены отдельным последовательным прогоном.
