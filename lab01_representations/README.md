# Лабораторная №1 — Один текст, разные представления

Автор: Дущенко Даниил Александрович, группа К3341.

Главный файл сдачи: `lab01.ipynb` (выполнены все ячейки по порядку), `report.docx`, `report.pdf`.

Из корня репозитория:

```powershell
.venv/Scripts/python.exe -m lab01_representations.run
```

Для notebook выберите ядро среды из `requirements-lock.txt` и выполните Run All. 150 исходных текстов уже включены в `data/texts.csv`, загрузка RuSentiment для повторения этой работы не нужна. `data/transformations.csv` содержит девять преобразований с семантическими суждениями. `results/` — признаки, словари, разреженные матрицы, плотные векторы, графики, таблица и аудит.

SentenceTransformer использует `intfloat/multilingual-e5-small` на CPU. Если доступна локальная копия, задайте `AOT_EMBEDDING_PATH`; по умолчанию проверяется `E:/AI/models/embeddings/multilingual-e5-small`, иначе модель загружается с Hugging Face. Семантические суждения я сформулировал при подготовке преобразований и затем сопоставили с косинусным сходством. Девять пар являются иллюстрацией, а не статистической оценкой распространённости ошибок.
