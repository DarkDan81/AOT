# Лабораторная 6: AI-детектив

Полностью вымышленный инцидент турнира «Орион»: девять документов, 5046 слов, 36 атомарных утверждений, 12 вопросов шести типов. Скрытая последовательность создана раньше документов и не передаётся модели. Работа выполнена с моделируемыми ролями ИИ; реальные независимые студенты не привлекались.

Из корня общего репозитория (PowerShell):

```powershell
uv pip install --python .venv/Scripts/python.exe -r lab06_ai_detective/requirements.txt
.venv/Scripts/python.exe -I -m pytest lab06_ai_detective/tests -q
.venv/Scripts/python.exe -I lab06_ai_detective/run_experiment.py
.venv/Scripts/python.exe -I lab06_ai_detective/evaluate.py
.venv/Scripts/python.exe -I -m streamlit run lab06_ai_detective/app.py --server.headless true
```

Нужен запущенный LM Studio на http://localhost:1234/v1 и модель `mistralai/ministral-3-14b-reasoning`. Общий транспорт — `common/llm.py`, параметры temperature=0, seed=42, max_tokens=1500, один системный промпт. Нет скрытых повторов или исправления JSON. Runner возобновляет только ещё не записанные run_id; неудачные запросы также сохраняются. Для короткой проверки доступен `--limit 1`, для отдельной группы `--kind baseline`.

A получает все документы плюс реестр идентификаторов для ссылок. B получает BM25 top-15. C получает тот же набор записей с теми же полями, сгруппированный по ветвям p=3 и упорядоченный по времени. Отличаются только упаковка и порядок. A заведомо содержит больше информации; B/C контролируют информационный состав. Ветка не является вероятностью истинности.

Данные и эталоны находятся в `data/`; `gold_freeze.json` содержит хеши исходных файлов до инференса. `variants.jsonl` хранит полный исходный/изменённый состав через исходный baseline каждого вопроса и полные копии вариантов, ожидаемые статусы и сведения о проверке. Результаты — `results/responses.jsonl`, точные контексты — `results/contexts/`, таблицы — `results/*.csv`.

120 запланированных измерений: 36 базовых, 36 перестановок, 36 добавлений противоречия и 12 удалений посылки для четырёх применимых вопросов. Остальные удаления явно N/A. Сбой транспорта не подменяется эталоном. Автоматическая валидация не доказывает семантическую верность объяснения; тест insufficient запрещает выдуманный ненулевой ответ, но свободный текст explanation требует отдельного анализа.

Роли: автор-агент — досье, эталоны, все модули, интерфейс и эксперимент; ведущий агент — независимая проверка логики и общая интеграция; агент ЛР5 — независимый аудит claims, временных связей и стресс-gold. Все проверяющие получили архитектуру. Обзор и ограничения: `data/review.md`. Реальные эпизоды использования ИИ: `AI_LOG.md`.

`build_data.py` и `build_variants.py` воспроизводят зафиксированные данные; после запуска модели эталоны не редактируются по её ответам. Служебные скрипты однократной редакции не нужны для воспроизведения и не запускаются.
